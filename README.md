# Dr. Eleanor Hayes — Psychology Practice Website

A clean, responsive one-page website for a clinical psychology practice. Built with plain HTML, CSS, and JavaScript — no frameworks, no build tools.

---

## Pages / Sections

Hero · About · Services · How It Works · Testimonials · Contact · Footer

## Features

- Fully responsive (mobile hamburger menu included)
- Smooth scroll + Intersection Observer reveal animations
- Sticky nav with scroll shadow
- Real photos via Unsplash
- Appointment request form with submit feedback
- Zero dependencies — just open `index.html`



## File Structure

```
├── index.html
├── style.css
├── script.js
└── README.md
```

## Customisation

Search and replace `Dr. Eleanor Hayes` with your name, update contact details in the Contact section, and swap the Unsplash image URLs with your own photos.
